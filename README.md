# Doorman

A standalone, interactive slide deck exploring the architecture of the Pi Agent Toolkit.

## Run locally

Open [`pi-agent-toolkit-deck.html`](./pi-agent-toolkit-deck.html) in a browser, or serve the directory with any static web server:

```bash
python3 -m http.server
```

Then visit <http://localhost:8000/pi-agent-toolkit-deck.html>.
